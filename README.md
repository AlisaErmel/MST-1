# 🎧 MY HeadPhones 🖤💜🤍

Welcome to **MY HeadPhones** – a sleek, interactive, and fully responsive website for exploring the latest headphones.  
This project demonstrates **animation, theme switching, and smooth navigation**, designed to provide a modern shopping experience.

---

## 🌟 Features

### 🖤 Top Navigation
- A **fixed top navigation bar** for easy browsing between sections.  
- Smooth scroll and interactive hover effects.  
- Quick access to **Home**, **About**, and **Contact**.

### 🎨 Theme Switcher
- Toggle between **Light** 🤍 and **Dark** 🖤 modes.  
- The website remembers your choice using the browser's **local storage**.  
- Subtle **purple 💜 accents** for a modern and stylish look.

### 🖼️ Animated Product Images
- Headphones images with **hover animations**.  
- Smooth **fade-ins, scaling effects, and rotations** for a dynamic feel.  
- Fully responsive across desktop and mobile devices.

---

## ⚡ Technologies Used

- **HTML5 & CSS3** – for structure and styling  
- **JavaScript** – for animations, theme toggle, and interactivity  
- **CSS Animations & Transitions** – smooth hover and fade effects  
- **Responsive Design** – mobile-first approach  

---

## 🎨 Colors & Icons Used

- **White 🤍** – clean backgrounds and text highlights  
- **Black 🖤** – bold text, headers, and navigation  
- **Purple 💜** – accent color for buttons, hover effects, and highlights  
- **Icons & Emojis** – used to enhance sections and improve readability
